# Implementation Prompt: 4.1 "My Learning" Dashboard & Full Live Integration

## 1. Goal
Complete the remaining tasks from Phase 2, Phase 4, and Phase 5 of the Vibelearn Roadmap:
1. Build the dedicated "My Learning" Dashboard (`src/pages/my-learning-page.tsx`) displaying learner statistics, enrolled/in-progress courses with real progress bars, and "Resume" buttons.
2. Update `/my-learning` route in `src/App.tsx` to render `MyLearningPage`.
3. Wire the frontend pages (`CoursesPage`, `CourseDetailPage`, `LearningPage`) to consume the live `courseService` and `progressService` with graceful fallback.
4. Integrate video resume timestamp persistence and interactive "Mark as Complete" toggling on `LearningPage`.
5. Add Vercel deployment configuration (`vercel.json`) with SPA routing rules.

- `AGENTS.md`: Full-stack architecture, Clerk auth gated routes, YouTube video embed rules, and theme design tokens (`DESIGN.md`, `src/globals.css`).

## 3. Code & Config Inspected
- `src/App.tsx`: Currently routes `/my-learning` to `LearningPage`. Needs update to `MyLearningPage`.
- `src/pages/learning-page.tsx`: In-memory `completedLessonIds`. Needs connection to `progressService`.
- `src/pages/courses-page.tsx`: Static mock progress calculation. Needs connection to `courseService` & `progressService`.
- `src/pages/course-detail-page.tsx`: Static course lookup. Needs connection to `courseService` & `progressService`.
- `src/services/course-service.ts` & `src/services/progress-service.ts`: Implemented in Phase 3 with local fallback.

## 4. Decisions & Assumptions
1. **My Learning Dashboard UI**:
   - Header with learner avatar and greeting from Clerk (`useUser()`).
   - Summary statistics cards (Courses Enrolled, Completed Lessons, Hours Learned).
   - Filter tabs: All Courses, In Progress, Completed.
   - Course cards displaying progress percentage, completion fractions (`X / Y lessons`), and quick "Resume" button pointing directly to the learner's last visited lesson.
   - Empty state with "Explore Courses" button when no progress exists yet.
2. **Resilience & Graceful Fallback**:
   - All pages use `courseService` and `progressService`. If Supabase tables are not yet created or the network is offline, the services seamlessly fall back to local storage and mock seed courses.
3. **Deployment Configuration**:
   - `vercel.json` ensures client-side routing (`/courses/*`, `/my-learning`, etc.) resolves to `/index.html`.
