## Decisions and Assumptions
- Implement `LearningPage` component in `src/pages/learning-page.tsx` (and link `MyLearningPage` to support both `/courses/:id/learn` and `/my-learning`).
- Make the learning page dynamic: load course data by `id` from route params (e.g. `/courses/:id/learn` or `/my-learning?course=1`), defaulting to Course 1 ("Next.js for Production").
- In `CourseDetailPage`, update the "Continue Learning ->" buttons to point to `/courses/${course.id}/learn`.
- In `CourseCard`, maintain clean navigation to course details and allow direct access to learning.
- Match `docs 2/design/learning-page.png` layout, typography, colors, and responsive behavior:
  - Desktop: Split layout with fixed/sticky collapsible curriculum sidebar on the left and full lesson player/content on the right.
  - Tablet/Mobile: Responsive stacked layout with a collapsible sidebar drawer.
  - Tab switching between "Lesson Content" and "Notes".
  - Full support for both light and dark themes using semantic tokens.
