# Implementation Prompt: 2.8 Seed Data Integration (Course & Lesson Content with Videos)

## 1. Goal
Populate and integrate the authentic course and lesson dataset from `docs/seed.ndjson` into the frontend application. This will replace the hardcoded placeholder courses with the 10 real courses, 40 modules, and 120 lessons (including YouTube video embeds, lesson durations, rich notes, key points, learning outcomes, and instructor biographies) across the Catalog, Course Detail, and Lesson Learning pages.

## 2. Skills & Guidelines Consulted
- `AGENTS.md`: Strict loop, technology lock, YouTube embed requirement (must stay on site via YouTube embed; no custom player; never send learner out to provider), theme tokens, and component boundaries.
- `docs/roadmap.md`: Phase 2 (Frontend First - UI & Layouts).
- `docs/system_design/frontend.md`: Read-only course and lesson presentation, clean typing, semantic styling.
- `DESIGN.md`: Strict theme tokens, colors, typography (`font-sans`, `font-display`), and radius/shadow tokens.

## 3. Code & Data Inspected
- `docs/seed.ndjson`: 6 categories, 5 instructors, 10 courses, and 120 lessons with valid YouTube URLs (`videoUrl`), thumbnails, duration in seconds, rich text notes, key points, pro tips, and resources.
- `src/types/courses.ts`: Current course, module, and learning outcome types. Needs extension to support `CourseLesson` (with `videoUrl`, `youtubeVideoId`, `durationFormatted`, `freePreview`, `notes`, `keyPoints`, `proTip`, `resources`) and rich `CourseModule`.
- `src/lib/mock-data.ts`: Current static placeholder courses. Will be transformed and populated with the parsed seed data.
- `src/pages/course-detail-page.tsx`: Course detail view displaying syllabus, module accordion, learning outcomes, instructor info, and links to `/courses/:id/learn`.
- `src/pages/learning-page.tsx`: Learning view currently displaying static mock video and curriculum sidebar. Needs to dynamically load the course's modules and lessons, embed the actual YouTube video using an `iframe`, and switch lessons seamlessly upon user selection.

## 4. Decisions & Assumptions
1. **YouTube Embed**: In accordance with `AGENTS.md` Rule 6 ("Playback stays on the site through a YouTube embed. Do not build a custom player. Videos are shown on the lesson page with the provider's own player."), the video player on `LearningPage` will use a responsive `iframe` embedding `https://www.youtube-nocookie.com/embed/${youtubeId}?autoplay=1&rel=0` with standard fullscreen and allow attributes.
2. **Backward Compatibility & Routing**:
   - Each course will retain an integer `id` (1 to 10) while also having its canonical `slug` (e.g. `nextjs-app-router-in-depth`).
   - Lookups will support both `c.id === Number(id)` and `c.slug === id`.
3. **Curriculum Navigation**:
   - The curriculum sidebar on `LearningPage` will dynamically render the active course's real modules and lessons.
   - Clicking any lesson in the curriculum sidebar will select it, update the video player to that lesson's YouTube video, update the lesson title and breadcrumbs, and display the lesson's actual notes and key points in the Content and Notes tabs.
   - The first lesson or now-playing lesson will be selected by default when entering the page.
4. **Data Transformation**:
   - We will generate a structured data module in `src/lib/seed-courses.ts` or directly update `src/lib/mock-data.ts` by resolving category, instructor, module, and lesson references from `docs/seed.ndjson`.

## 5. Files to Touch
- `src/types/courses.ts`: Extend `Course`, `CourseModule`, and add `CourseLesson`, `LessonResource`.
- `src/lib/mock-data.ts`: Populate with the complete 10 courses and their 120 lessons from `docs/seed.ndjson`.
- `src/pages/course-detail-page.tsx`: Support dynamic modules and lessons from seeded courses, including lesson durations and preview badges.
- `src/pages/learning-page.tsx`: Implement dynamic curriculum sidebar, active lesson state, real YouTube embed player, and lesson notes/key points rendering.
- `docs/roadmap.md`: Update task status upon completion.

## 6. Requirements
- All 10 courses from `docs/seed.ndjson` must be accessible in the catalog (`/`, `/courses`).
- Navigating to `/courses/:id` displays the course's genuine title, cover image, category, level, instructor, outcomes, modules, and lessons.
- Navigating to `/courses/:id/learn` loads the course's real curriculum and plays the real YouTube video of the selected lesson.
- Clicking any lesson in the sidebar switches the video and displays its corresponding notes.
- Light and dark mode support remains fully functional with zero styling regressions.

## 7. Security Considerations
- Use `https://www.youtube-nocookie.com/embed/` for enhanced privacy.
- Sanitize video IDs to alphanumeric and hyphen/underscore characters to prevent injection.
- Ensure all external links use `rel="noopener noreferrer"`.

## 8. Acceptance Criteria
- [ ] `src/types/courses.ts` defines comprehensive types for courses, modules, lessons, and resources.
- [ ] `src/lib/mock-data.ts` contains all 10 seeded courses with their respective 40 modules and 120 lessons with valid YouTube video IDs.
- [ ] Course Detail Page renders the real modules, lessons, durations, and instructor details.
- [ ] Lesson Page embeds the authentic YouTube video for each lesson and allows switching lessons via the sidebar.
- [ ] Lesson Page Content and Notes tabs render real lesson text, key points, and pro tips.
- [ ] `npm run lint` and `npm run build` pass with zero errors.
