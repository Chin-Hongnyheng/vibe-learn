## UI Spec

Layout: page header "My Habits" + "+ Add Habit" button. Summary bar (3 stat cards). Habit list. Inline add form.

Habit Card: bg-card border border-border rounded-lg shadow-sm p-4.
- Left: circle toggle (bg-primary when complete, outlined when not)
- Center: title font-semibold, category badge bg-accent rounded-full text-xs, target text-muted-foreground text-sm
- Right: trash icon, hover:text-destructive, spinner while deleting

Add Form fields: title (required), description, category (select), frequency (select daily/weekly), targetCount (number), unit.

States: loading skeleton (animate-pulse), empty state CTA, error banner.

## Requirements

1. Wire useUser() to get userId for all API calls.
2. On mount call getHabitsWithTodayStatus(userId).
3. createHabit on form submit, append to state.
4. logHabit to toggle completion, update state in place.
5. deleteHabit on trash click, filter from state on success.
6. Loading/error states per spec.
7. Only existing design tokens — no arbitrary hex/px.

## Acceptance Criteria

2. Habits list from Supabase renders.
3. Toggle, add, delete all work and reflect in Supabase.
4. npm run lint passes 0 errors.
