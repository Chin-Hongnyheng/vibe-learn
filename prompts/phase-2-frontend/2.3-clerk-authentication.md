# 2.3 & 2.4 — Clerk Authentication & Protected Routes

## Goal
Integrate the Clerk React SDK (`@clerk/clerk-react`) into the React (Vite) application using the existing `VITE_CLERK_PUBLISHABLE_KEY` from `.env`. Implement Sign In and Sign Up routes with Clerk prebuilt components, replace the static user avatar in the header with Clerk's `<SignedIn>` / `<UserButton>` and `<SignedOut>` / `<SignInButton>`, and protect private routes (`/my-learning`, `/courses/:id/learn`) using Clerk auth guards.

## Decisions and Assumptions
1. **Clerk Package**: Install `@clerk/clerk-react` via `npm install @clerk/clerk-react`.
2. **Provider Setup**: Wrap `<App />` inside `<ClerkProvider publishableKey={PUBLISHABLE_KEY}>` in `src/main.tsx` or `src/App.tsx`. Read `import.meta.env.VITE_CLERK_PUBLISHABLE_KEY` with a clear runtime check.
3. **Authentication UI**:
   - Create `src/pages/sign-in-page.tsx` rendering Clerk's `<SignIn path="/sign-in" routing="path" signUpUrl="/sign-up" />` centered on a clean page with Vibe Learn branding.
   - Create `src/pages/sign-up-page.tsx` rendering Clerk's `<SignUp path="/sign-up" routing="path" signInUrl="/sign-in" />` centered similarly.
   - Register `/sign-in/*` and `/sign-up/*` routes in `src/App.tsx`.
4. **Header Auth Controls**:
   - In `src/sections/navigationsection.tsx`:
     - When Signed Out: Display a "Sign In" button that links to `/sign-in` (or opens Clerk modal/redirect) styled with `bg-primary-500 hover:bg-primary-600 text-white rounded-xl px-4 py-2 text-sm font-semibold`.
     - When Signed In: Display Clerk's `<UserButton afterSignOutUrl="/" />` seamlessly styled to fit the 40px avatar container.
5. **Route Protection**:
   - Create a reusable `ProtectedRoute` component in `src/components/auth/protected-route.tsx` utilizing `<SignedIn>` and `<SignedOut><RedirectToSignIn /></SignedOut>`.
   - Protect `/my-learning` and `/courses/:id/learn` so unauthenticated visitors are smoothly redirected to `/sign-in`.
6. **Design System & Theme**:
   - Clerk components will respect the design system and light/dark theme.

## Requirements
1. `@clerk/clerk-react` installed and initialized with `VITE_CLERK_PUBLISHABLE_KEY`.
2. Dedicated `/sign-in/*` and `/sign-up/*` pages with Clerk prebuilt components.
