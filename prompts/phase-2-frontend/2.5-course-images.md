# 2.5 — Generate Custom Course Images for All 10 Courses

## Goal
Generate 10 custom, professional course icon/badge images corresponding to each course's subject matter in the Vibe Learn catalog. Replace the generic `picsum.photos` placeholders in `src/lib/mock-data.ts` with local, high-fidelity visual assets stored in `src/assets/courses/`.

## Skills and Guidelines Read
- `AGENTS.md`: Section 1 (platform scope), 2 (loop rules), 3 (UI reproduction & theme consistency), 11 (strict system design), and 12 (npm commands).
- `docs/system_design/frontend.md`: Folder structure (`src/assets/`), component architecture, design system first.
- `DESIGN.md`: Section 12 ("Course Card (Catalog & Home): Top Row: Course Icon / Logo badge (e.g., Next.js 'N', Docker whale, TypeScript 'TS') + Arrow button ->"), rounded-2xl radii, emerald and slate color harmonies.
- Reference Images: `docs/design/home-page.png` and `docs/design/course-page.png` displaying clean, recognizable tech badges with dark/slate containers and emerald/brand accents.

## Inspected Code and Configuration
- `src/lib/mock-data.ts`: All 10 courses currently use placeholder URLs (`https://picsum.photos/seed/vertex-.../1600/900`).
- `src/components/common/course-card.tsx`: Renders course images within a `size-20 overflow-hidden rounded-2xl bg-neutral-900` container.
- `src/pages/course-detail-page.tsx`: Displays the course cover image in the header/hero area.
- `src/assets/`: Existing directory for static brand images (`logo.png`, `hero-learning.png`).

## Decisions and Assumptions
1. **Visual Style & Consistency**:
   - Each course image will be a clean, modern, high-contrast icon/badge on a dark slate background (`#0F172A`) with subtle emerald (`#10B981`) and topic-specific accent highlights, matching the reference images in `docs/design/home-page.png`.
   - Aspect ratio: 1:1 square (optimal for the `size-20 rounded-2xl` card badge and crisp scaling).
2. **The 10 Courses**:
   - Course 1 (`nextjs-app-router-in-depth`): Next.js "N" logo with glowing emerald accents and modern dark slate styling.
   - Course 2 (`react-performance-engineering`): React atom symbol with high-speed performance trails and cyan/emerald glow.
   - Course 3 (`typescript-for-application-developers`): TypeScript "TS" symbol on royal blue badge with code accents.
   - Course 4 (`building-ai-apps-with-llms`): AI neural network brain with glowing synaptic connections and sparkles.
   - Course 5 (`retrieval-augmented-generation-from-scratch`): RAG vector embedding space connecting documents to search query.
   - Course 6 (`python-for-data-work`): Stylized Python serpents with data visualization bar graphs and analytics nodes.
   - Course 7 (`system-design-foundations`): Distributed architecture diagram with load balancers, servers, and databases.
   - Course 8 (`postgresql-for-developers`): PostgreSQL elephant silhouette integrated with relational database cylinders.
   - Course 9 (`devops-with-docker-and-kubernetes`): Docker whale and Kubernetes helm steering wheel with container blocks.
   - Course 10 (`practical-web-security`): Cyber security shield with glowing digital padlock and cryptographic code pattern.
3. **Asset Storage & Integration**:
   - Save generated image files to `src/assets/courses/`.
   - Update `src/lib/mock-data.ts` to import or reference these 10 local image assets for `imgUrl` on each course.
4. **Build & Quality Verification**:
   - Verify all images load without broken links or layout shifts.
   - Run `npm run lint` and `npm run build` to confirm zero errors.
