# 2.8 — Supabase Integration (Replace Mock Data)

## Goal

Install `@supabase/supabase-js`, set up the Supabase client, define the database schema that mirrors `src/lib/mock-data.ts`, provide a SQL seed script, create typed fetch functions in `src/lib/api/courses.ts`, and update every page and section that currently imports `MOCK_COURSES` to fetch live data from Supabase instead.

---

## Architecture Note

AGENTS.md §4 requires the frontend to hold **no direct database connection** — all reads and writes should go through an Express backend. However, **no backend folder exists yet** in this repo. Proceeding with a direct Supabase JS client in the frontend is the only viable path right now.

**Mitigation**: Only the anon (public) key is used, RLS policies restrict all tables to `SELECT` for anonymous users, and no secret key ever touches the browser. When the backend is built, the fetch layer in `src/lib/api/courses.ts` can be retargeted to the Express endpoints without touching any page or component.

## Decisions & Assumptions

1. **Package**: Add `@supabase/supabase-js` to `dependencies`.

2. **Env vars** (never expose secret key to browser):
```
VITE_SUPABASE_URL=https://<project-ref>.supabase.co
VITE_SUPABASE_ANON_KEY=<anon-public-key>
```

3. **Schema** — three tables to match the mock data shape, plus a jsonb column for learningOutcomes:

```sql
create table instructors (
  id bigint primary key generated always as identity,
  name text not null,
  avatar text not null,
  bio text
);

create table courses (
  id bigint primary key generated always as identity,
  title text not null,
  description text not null,
  category text not null,
  tag text not null,
  img_url text not null,
  level text not null check (level in ('Beginner','Intermediate','Advanced')),
  duration_minutes integer not null,
  rating numeric(3,1) not null default 0,
  reviews integer not null default 0,
  enrolled integer not null default 0,
  price numeric(10,2) not null default 0,
  is_free boolean not null default false,
  is_featured boolean not null default false,
  language text not null default 'English',
  learning_outcomes jsonb,
  instructor_id bigint references instructors(id),
  created_at timestamptz not null default now()
);

create table modules (
  id bigint primary key generated always as identity,
  course_id bigint references courses(id) on delete cascade,
  title text not null,
  description text,
  duration text,
  position integer not null
);
```

4. **RLS** — enable on all tables, anon SELECT only:
```sql
alter table courses enable row level security;
alter table instructors enable row level security;
alter table modules enable row level security;
create policy "public read courses" on courses for select using (true);
create policy "public read instructors" on instructors for select using (true);
create policy "public read modules" on modules for select using (true);
```

5. **Supabase client** — `src/lib/supabase.ts`

6. **Fetch layer** — `src/lib/api/courses.ts` with typed functions:
   - `getCourses(): Promise<Course[]>`
   - `getCourseById(id: number): Promise<Course | null>`
   - `getFeaturedCourses(limit?: number): Promise<Course[]>`
   Each maps snake_case DB rows back to the camelCase `Course` type.

7. **Page updates** — replace synchronous MOCK_COURSES with async useState+useEffect:
   - `src/pages/courses-page.tsx` → getCourses()
   - `src/pages/course-detail-page.tsx` → getCourseById(courseId)
   - `src/sections/coursesection.tsx` → accept courses as prop only (no default)
   - `src/pages/home-page.tsx` → fetch getFeaturedCourses(3), pass as prop to CourseSection
   - `src/pages/learning-page.tsx` → getCourseById(courseId)
   Add loading skeleton and inline error state for each.

8. **My Learning page stays mock** — real progress needs the backend. Will be wired later.

9. **Seed script** — `src/lib/supabase-seed.sql` INSERTs all 10 courses from mock-data.ts.

10. **mock-data.ts stays** — do not delete it.

- Never use the service_role key in frontend code.
